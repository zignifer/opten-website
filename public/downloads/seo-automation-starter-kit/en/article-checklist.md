# SEO article pre-publication checklist

## Content

- [ ] The topic matches the query and search intent.
- [ ] The article answers the main question near the beginning.
- [ ] There are no invented facts, cases, reviews, or outcomes.
- [ ] Every number and changing rule has a current source.
- [ ] Wordstat frequency is not described as people, customers, or sales.
- [ ] The call to action fits the page and the business.

## SEO

- [ ] Title, description, and H1 are unique.
- [ ] There is one clear canonical URL.
- [ ] RU and EN versions use hreflang when both exist.
- [ ] The page is included in the sitemap.
- [ ] Schema matches the visible page content.
- [ ] Internal links point to existing pages.

## Images

- [ ] Every image has useful alt text.
- [ ] Text inside images is spelled correctly.
- [ ] Images remain readable on mobile.
- [ ] File sizes meet the website requirements.
- [ ] Source and reference rights are confirmed.

## Technical and live checks

- [ ] The website build completes without errors.
- [ ] There are no new browser-console errors.
- [ ] The page is reviewed at mobile and desktop widths.
- [ ] Buttons and downloads open correctly.
- [ ] The live URL serves the new page.
- [ ] The topic changes to `published` only after the live check.
