# Чек-лист SEO-статьи перед публикацией

## Содержание

- [ ] Тема соответствует запросу и намерению пользователя.
- [ ] Статья отвечает на главный вопрос в начале.
- [ ] Нет выдуманных фактов, кейсов, отзывов и результатов.
- [ ] Все числа и изменяемые правила имеют актуальный источник.
- [ ] Частотность Wordstat не названа количеством людей, клиентов или продаж.
- [ ] Призыв к действию соответствует странице и бизнесу.

## SEO

- [ ] Уникальные title, description и H1.
- [ ] Один понятный canonical.
- [ ] RU и EN связаны через hreflang, если обе версии существуют.
- [ ] Страница добавлена в sitemap.
- [ ] Schema соответствует видимому содержанию.
- [ ] Внутренние ссылки ведут на существующие страницы.

## Изображения

- [ ] У каждого изображения есть понятный alt.
- [ ] Текст внутри изображения написан без ошибок.
- [ ] Изображения читаются на мобильном экране.
- [ ] Размер файлов подходит требованиям сайта.
- [ ] Есть права на исходники и референсы.

## Техника и публикация

- [ ] Сборка проходит без ошибок.
- [ ] В консоли браузера нет новых ошибок.
- [ ] Страница проверена на мобильной и десктопной ширине.
- [ ] Кнопки и материалы для скачивания открываются.
- [ ] Живой URL возвращает новую страницу.
- [ ] Тема отмечена как `published` только после живой проверки.
