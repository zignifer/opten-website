# Visual production plan — vibe-coding-freelance

## Article art direction

- Medium: cinematic architectural model-making studio photographed as a real practical set, with website sections represented as translucent physical modules rather than fake app UI.
- Materials: frosted acrylic page sections, tracing paper, anodized black aluminum rails, steel registration pins, vellum notes, and one warm paper sketch.
- Background: deep teal-black `#011417`.
- Accent: exact Opten lime `#9CFB51`, plus restrained off-white paper and one muted amber approval marker.
- Typography treatment: flat printed Bebas Neue on acetate or paper strips; never extruded, embossed, beveled, engraved, backlit as dimensional lettering, or built as separate 3D letters.
- Line language: precise architectural measurement ticks and one continuous `#9CFB51` registration rail with a consistent thin stroke.
- Light and grain: raking workshop light, crisp edge highlights on acrylic and metal, soft shadow falloff, subtle analog grain, no glossy SaaS render.
- Recurring motif: one lime registration rail and small round steel pins appear naturally in every inline frame.
- Card/grid frames: 0
- Old blog usage: composition bank only. Never attach old article JPGs to the generator because their typography is obsolete.
- Style anchor: Frame 1 RU. Later frames inherit the physical medium, color grade, flat typography, rail thickness, steel pins, and light, but must not copy its layout, camera, or object arrangement.
- RU language rule: all explanatory text is Cyrillic. English remains only in the product name Codex when it appears in article copy, not in the image labels.
- Brief reconciliation: the older brief suggested `PROMPT`; the current Russian-language pipeline requires `ПРОМПТ`. The frame uses the Cyrillic form.

## Cover — WEBSITE BUILD ATELIER

- Story beat: a website is assembled like a small architectural object from requirements, layout, components, and checks.
- Visual proof: one vertical aluminum construction rig holds a long frosted-acrylic page model while two real hands align a new section against measurement marks; a warm paper sketch and color swatches sit at the base.
- Composition: cinematic architectural hero object
- Text mode: none
- Text: no text, no logos, no readable interface.
- Style continuity: same materials, deep teal-black, exact lime registration rail, steel pins, raking light, and analog grain as the inline series.
- Semantic job: establish the physical build-and-review metaphor without using a laptop dashboard, floating UI board, or connector network.

## Frame 1 — TASK / ЗАДАЧА

- Story beat: the first useful vibe-coding project is one small result with a visible finish line.
- Visual proof: a warm paper sketch on the left passes through a physical registration gate and becomes one complete translucent landing-page model on the right.
- Composition: transformation diptych
- Text mode: contrast-pair
- RU text: `ЗАДАЧА`, `ИДЕЯ → РАБОЧИЙ ЭКРАН`.
- EN text: `TASK`, `IDEA → WORKING PAGE`.
- Style continuity: frosted acrylic, tracing paper, black rails, exact lime registration line, steel pins, flat Bebas Neue, raking light, and grain.
- Semantic job: show the concrete transformation from an idea to one testable page instead of listing website categories.

## Frame 2 — LAYOUT / МАКЕТ

- Story beat: a useful technical brief turns a vague request into a page with a deliberate order and mobile behavior.
- Visual proof: a tall exploded architectural section of one landing page shows the same content modules locking into a desktop rail and a narrow mobile rail, while an empty rejected module remains outside the assembly.
- Composition: vertical exploded blueprint
- Text mode: sequence
- RU text: `МАКЕТ`, `СМЫСЛ → БЛОКИ → МОБИЛЬНАЯ ВЕРСИЯ`.
- EN text: `LAYOUT`, `PURPOSE → SECTIONS → MOBILE`.
- Style continuity: same physical materials, lime rail weight, pins, flat type, light, grain, and background, with a new vertical camera and no diptych layout.
- Semantic job: make information hierarchy and responsive adaptation visible as parts of one object.

## Frame 3 — PROMPT / ПРОМПТ

- Story beat: the prompt is useful when it carries a project through a short, testable production loop.
- Visual proof: one printed instruction sheet travels through a circular mechanical proofing rig; each quarter physically changes the same acrylic page model before it reaches the release gate.
- Composition: circular proofing timeline
- Text mode: sequence
- RU text: `ПРОМПТ`, `ТЗ → СБОРКА → ПРОВЕРКА → ПУБЛИКАЦИЯ`.
- EN text: `PROMPT`, `BRIEF → BUILD → TEST → PUBLISH`.
- Style continuity: same acrylic, black metal, lime rail, steel pins, flat Bebas Neue, raking light, and grain, without repeating the prior split or vertical layout.
- Semantic job: connect instructions, building, testing, and publishing as one causal cycle rather than four unrelated labels.

## Frame 4 — PROJECT / ПРОЕКТ

- Story beat: the first freelance service needs a checked result and a clear handoff, not a claim that AI can build anything.
- Visual proof: a finished acrylic landing-page model passes through a metal inspection gate into a slim project case held by a human hand; a single rejected oversized module stays behind.
- Composition: handoff decision point
- Text mode: contrast-pair
- RU text: `ПРОЕКТ`, `ПРОВЕРЕН → ПЕРЕДАН`.
- EN text: `PROJECT`, `TESTED → HANDED OFF`.
- Style continuity: same material system, exact lime, pins, flat type, light, grain, and background, with a close inspection camera and no timeline or blueprint repetition.
- Semantic job: show that the sellable output is the tested handoff, not the generation method.
