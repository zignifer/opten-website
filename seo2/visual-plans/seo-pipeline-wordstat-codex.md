# Visual production plan - seo-pipeline-wordstat-codex

## Article art direction

- Medium: cinematic editorial product photography where an SEO workflow is staged with physical folders, paper, lenses, check tools, keys, stamps, and an industrial conveyor.
- Background: deep teal-black `#011417` studio environment with large areas of negative space.
- Accent: exact Opten lime `#9CFB51`, white, graphite, and small neutral metal highlights.
- Typography treatment: flat generated Bebas Neue-style uppercase lettering with tall condensed forms, printed inside the raster image.
- Line language: sparse lime crop marks, short arrows, checkpoints, and thin callout rules.
- Light: hard controlled studio light with deep shadows, restrained reflections, and crisp material texture.
- Information density: one large headline and no more than five short labels per frame, except subordinate query examples in Frame 1.
- Card/grid frames: 1
- Card/grid note: Frame 2 is the only card-like matrix, represented as four physical folders.
- Style anchor: the RU version of Frame 1 establishes the black and lime Opten visual system. English siblings preserve each composition and localize only the text.
- Language rule: RU frames use Russian text. EN siblings use natural English text. The shared cover is intentionally bilingual because the user requested text inside every generated image.

## Cover - SEO conveyor

- Story beat: Wordstat demand becomes a topic, then an article, and finally a checked publication.
- Visual proof: an industrial black conveyor carries a search sheet, topic card, article proof, and approval stamp through four physical stations.
- Composition: wide industrial conveyor
- Text mode: sequence
- Style continuity: exact lime, flat tall condensed type, dark studio materials, sparse guide lines, and hard side light used by all article frames.
- Visible text: `SEO-КОНВЕЙЕР`, `SEO PIPELINE`, `WORDSTAT`, `TOPIC`, `ARTICLE`, `CHECK`.

## Frame 1 - СНАЧАЛА СПРОС / DEMAND COMES FIRST

- Story beat: many raw phrases narrow into one useful search intent, while demand is kept separate from sales.
- Visual proof: a stack of query strips passes through two large optical lenses and exits as one selected article question.
- Composition: dual-lens demand filter
- Text mode: annotated-explainer
- RU text: `СНАЧАЛА СПРОС`, `ФРАЗЫ`, `НАМЕРЕНИЕ`, `НЕ ПРОДАЖИ`.
- EN text: `DEMAND COMES FIRST`, `PHRASES`, `INTENT`, `NOT SALES`.
- Style continuity: same black studio, exact lime, flat Bebas Neue-style type, corner guides, controlled reflections, and hard light.

## Frame 2 - ОДИН РЕЕСТР ТЕМ / ONE TOPIC REGISTRY

- Story beat: one persistent registry remembers which topics wait, pause, or have already been published.
- Visual proof: four physical folders stand in front of a single archive drawer, with the published folder highlighted in lime.
- Composition: physical status folder matrix
- Text mode: contrast-pair
- RU text: `ОДИН РЕЕСТР ТЕМ`, `В ОЧЕРЕДИ`, `ОТЛОЖЕНО`, `ОПУБЛИКОВАНО`, `БЕЗ ДУБЛЕЙ`.
- EN text: `ONE TOPIC REGISTRY`, `QUEUED`, `DEFERRED`, `PUBLISHED`, `NO DUPLICATES`.
- Style continuity: same matte-black materials, exact lime, flat condensed type, crop marks, deep shadows, and restrained highlights.

## Frame 3 - ОДНА КОМАНДА / ONE COMMAND

- Story beat: one plain-language command moves a topic through brief, article, check, and publication.
- Visual proof: a giant physical keyboard key starts a five-station workflow connected by a single glowing progress line.
- Composition: low-angle command runway
- Text mode: sequence
- RU text: `ОДНА КОМАНДА`, `НАПИШИ SEO-СТАТЬЮ`, `ТЕМА`, `ЗАДАНИЕ`, `СТАТЬЯ`, `ПРОВЕРКА`, `ПУБЛИКАЦИЯ`.
- EN text: `ONE COMMAND`, `WRITE AN SEO ARTICLE`, `TOPIC`, `BRIEF`, `ARTICLE`, `CHECK`, `PUBLISH`.
- Style continuity: same palette, flat tall type, black physical objects, sparse corner brackets, and a single lime direction line.

## Frame 4 - ПРОВЕРКА ДО ПУБЛИКАЦИИ / VERIFY BEFORE PUBLISH

- Story beat: facts, SEO, mobile layout, and build must pass before the article goes live.
- Visual proof: a printed website proof is inspected with a magnifier, phone, lens, and caliper while four checklist labels point to each tool.
- Composition: top-down inspection bench
- Text mode: annotated-explainer
- RU text: `ПРОВЕРКА ДО ПУБЛИКАЦИИ`, `ФАКТЫ`, `SEO`, `МОБИЛЬНЫЙ ЭКРАН`, `СБОРКА`.
- EN text: `VERIFY BEFORE PUBLISH`, `FACTS`, `SEO`, `MOBILE`, `BUILD`.

- Visual proof: an open rugged case contains four clearly labeled physical folders for the registry, checklist, brief, and Wordstat research.
- Composition: open starter-kit case
- Text mode: contrast-pair
- RU text: `НАЧНИ С ОДНОЙ ТЕМЫ`, `РЕЕСТР`, `ЧЕК-ЛИСТ`, `БРИФ`, `WORDSTAT`, `СТАРТОВЫЙ НАБОР`.
