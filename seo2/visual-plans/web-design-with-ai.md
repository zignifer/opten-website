# Visual plan: web-design-with-ai

## Art direction

- **Series concept:** a dark physical web-design workshop where translucent site sections move along one lime routing line from assignment to tested page. A matte-black browser frame, vellum modules, metal rulers, and one unfinished clay vessel recur across the series.
- **Medium/materials:** cinematic tabletop photography with translucent vellum, matte-black card, brushed aluminum rulers, frosted acrylic browser frames, paper wireframes, and a tactile clay object.
- **Background and light:** deep teal-black `#011417`, cool underlight through vellum, restrained side light on the clay, and exact lime accents `#9CFB51`.
- **Texture:** visible paper fibers, clay dust, fine scratches on aluminum, subtle film grain, and soft falloff; no glossy dashboard or floating-interface treatment.
- **Typography:** every visible word is rendered in the generated raster in Bebas Neue, condensed uppercase display sans-serif with tall narrow letters. Text stays flat and printed on paper or vellum, never extruded, embossed, metallic, or added in post.
- Typography treatment: flat printed Bebas Neue integrated into the raster; never extruded, embossed, metallic, or added in post.
- Card/grid frames: 0
- **Line language:** 3 px lime routing lines, crop corners, registration crosses, and sparse straight arrows.
- **Recurring motif:** the lime route links each learning decision to one testable page, while the matte-black browser frame shows the current boundary of the project.
- **Continuity:** preserve the physical workshop materials, clay vessel, browser frame, exact palette, flat Bebas Neue text, routing-line weight, cool light, and grain. Change the camera, layout, and composition archetype between frames.

## Cover

- **Story beat:** a learner turns scattered lessons into one complete website project.
- Visual proof: a wide workshop table holds a content sheet, grayscale wireframe, translucent layout modules, desktop and phone frames, and the recurring clay vessel, all connected by one lime routing line.
- Composition: cinematic wide studio landscape / diagonal project path with generous depth, no UI screenshot.
- Text mode: none.
- **Semantic job:** signals practical web-design learning, Figma-like layout construction, responsive outputs, and a finished project without pretending to show a real software interface.
- **Generation prompt:** Minimal cinematic physical web-design workshop, deep teal-black `#011417`, exact lime-green `#9CFB51` routing-line accents, one content sheet with abstract unreadable lines, grayscale paper wireframe, translucent vellum layout modules, matte-black desktop browser frame and phone frame, one unfinished clay vessel, brushed aluminum ruler, paper fibers, clay dust, subtle film grain and cool underlight, wide 16:9, no text, no letters, no logos, no real UI, no score indicator, no watermark.

## Frame 1: judge the finished project

- **Story beat:** choose a course by the complete outcome it teaches, not by lesson count.
- Visual proof: a tall stack of blank lesson slips stops at one side while a single assembled desktop-and-phone project stands inside the browser frame on the other; the lime route ends at the complete project.
- Composition: decision point / converging workshop path.
- **RU text:** `СМОТРИ НА РЕЗУЛЬТАТ`; labels `УРОКИ` and `ГОТОВЫЙ ПРОЕКТ`.
- **EN text:** `JUDGE THE OUTCOME`; labels `LESSONS` and `FINISHED PROJECT`.
- Text mode: contrast-pair
- Style continuity: this RU frame is the style anchor for the series. It defines flat Bebas Neue typography, vellum and matte-black materials, clay texture, lime routing-line weight, browser-frame geometry, cool underlight, grain, and color grading.
- **Semantic job:** makes the course-selection criterion visible as a choice between content volume and one testable outcome.

## Frame 2: one page through the full cycle

- **Story beat:** learn web design from scratch by taking one page through every production stage.
- Visual proof: one continuous lime route crosses four physical stations around the clay vessel: content sheet, grayscale wireframe, visual layout, and phone test.
- Composition: circular sequence / four-station tabletop journey.
- **RU text:** `ОДНА СТРАНИЦА — ВЕСЬ ЦИКЛ`; sequence `ТЕКСТ → КАРКАС → МАКЕТ → ТЕСТ`.
- **EN text:** `ONE PAGE — FULL CYCLE`; sequence `COPY → WIREFRAME → LAYOUT → TEST`.
- Text mode: sequence
- Style continuity: inherit the style anchor's materials, color grading, flat typography, lime route, browser-frame geometry, clay object, lighting, and grain. Do not copy its layout, camera, or object composition.
- **Semantic job:** shows why a complete small project teaches more than disconnected screen exercises.

## Frame 3: the layout system

- **Story beat:** build the Figma file from reusable rules instead of isolated decoration.
- Visual proof: one frosted browser frame is opened like a technical specimen, with aluminum rulers marking its container, column rhythm, type scale, and reusable component rail.
- Composition: anatomy / single browser-frame specimen with four callouts.
- **RU text:** `СЕТКА ДЕРЖИТ МАКЕТ`; callouts `КОНТЕЙНЕР`, `КОЛОНКИ`, `ТЕКСТ`, `КОМПОНЕНТЫ`.
- **EN text:** `THE GRID HOLDS THE PAGE`; callouts `CONTAINER`, `COLUMNS`, `TYPE`, `COMPONENTS`.
- Text mode: annotated-explainer
- Style continuity: inherit the style anchor's materials, color grading, flat typography, lime line weight, browser-frame geometry, clay dust, cool light, and grain. Do not copy its layout, camera, or object composition.
- **Semantic job:** turns the abstract idea of a Figma system into visible, inspectable page rules.

## Frame 4: divide the work between AI and Figma

- **Story beat:** use AI to produce a bounded hero asset while keeping interface layers editable.
- Visual proof: the recurring clay vessel appears as a finished editorial background passing through a narrow lime gate into a browser frame, where separate vellum headline, button, and grid layers remain physically movable.
- Composition: hero visual / material-to-layout transfer across one gate.
- **RU text:** `ИИ ДЕЛАЕТ МАТЕРИАЛ`; labels `ФОН` and `МАКЕТ В FIGMA`.
- **EN text:** `AI MAKES THE ASSET`; labels `BACKGROUND` and `FIGMA LAYOUT`.
- Text mode: contrast-pair
- Style continuity: inherit the style anchor's workshop medium, color grading, flat Bebas Neue treatment, lime route, browser-frame geometry, clay object, lighting, and grain. Do not copy its layout, camera, or object composition.
- **Semantic job:** proves the practical boundary from the named case: AI supplies one asset, while typography and layout remain editable.

## Pairing and production rules

1. Generate the cover separately without text.
2. Generate RU frame 1 with `seo2/Reference/bebas-neue-font-reference.png` as the only initial reference and inspect every Cyrillic word.
3. Use approved RU frame 1 as the style reference for RU frames 2-4, explicitly forbidding layout, camera, and composition copying.
4. Create each EN frame as a localization edit of its approved RU sibling: change only the text, preserve the object, layout, camera, light, routing lines, grain, and color.
5. Resize, compress, and convert only. Never add, replace, or redraw text after generation.
