# Visual plan: prompt-engineering-course

## Art direction

- **Series concept:** a dark physical prompt laboratory where instructions are assembled from translucent smoked-glass strips and tested against a single tangible target object. A precise lime optical rail connects task, context, constraints, output, and revision without turning the scene into software UI.
- **Medium/materials:** cinematic tabletop photography with smoked acrylic instruction strips, black stone, brushed aluminum clamps, translucent drafting film, graphite marks, and one matte ceramic target object.
- **Background and light:** deep teal-black `#011417`, narrow cool key light, restrained haze, and exact lime accents `#9CFB51`.
- **Texture:** stone dust, fine scratches, acrylic edge glow, paper fibers, graphite traces, and controlled film grain; no glossy dashboard treatment.
- **Typography:** every visible word is rendered in the generated raster in Bebas Neue, condensed uppercase display sans-serif with tall narrow letters. Text stays flat, printed on drafting film or acrylic labels, never extruded, embossed, metallic, or added in post.
- Typography treatment: flat printed Bebas Neue integrated into the raster; never extruded, embossed, metallic, or added in post.
- Card/grid frames: 0
- **Line language:** 3 px exact `#9CFB51` optical rails, round aluminum registration pins, sparse right-angle callouts, and small lime focus brackets.
- **Recurring motif:** one lime optical rail carries the instruction from an initial task toward a testable output.
- **Continuity:** preserve the stone laboratory, smoked acrylic, drafting film, aluminum pins, matte ceramic object, exact palette, flat Bebas Neue text, line weight, cool light, and grain. Change the camera, object arrangement, and composition archetype between frames.

## Cover

- **Story beat:** a prompt is built as a practical instrument rather than a magic phrase.
- Visual proof: a wide black-stone workbench holds several smoked acrylic instruction strips, a matte ceramic mug as the target, aluminum clamps, a drafting compass, and one continuous lime optical rail ending at a clean photographic frame.
- Composition: cinematic wide diagonal laboratory landscape with one clear assembly path, no text and no software interface.
- Text mode: none.
- **Semantic job:** signals hands-on prompt engineering, structure, constraints, and output testing without using a computer-screen metaphor.
- **Generation prompt:** Cinematic physical prompt laboratory on black stone, deep teal-black `#011417`, exact lime-green `#9CFB51` optical rail, smoked acrylic instruction strips, matte black ceramic mug as one target object, brushed aluminum clamps, drafting compass, translucent film, fine scratches, paper fibers, controlled film grain, narrow cool key light, wide 16:9, no text, no letters, no logos, no software UI, no score indicator, no watermark.

## Frame 1: define the result

- **Story beat:** a useful prompt starts with a concrete result, not with decorative wording.
- Visual proof: one matte ceramic target sits inside a clean photographic crop while three smoked-glass instruction strips point to the task, context, and output format that define it.
- Composition: anatomy / single target specimen with three right-angle callouts.
- **RU text:** `СНАЧАЛА ЗАДАЙТЕ РЕЗУЛЬТАТ`; callouts `ЗАДАЧА`, `КОНТЕКСТ`, `ФОРМАТ`.
- **EN text:** `DEFINE THE RESULT FIRST`; callouts `TASK`, `CONTEXT`, `FORMAT`.
- Text mode: annotated-explainer
- Style continuity: this RU frame is the style anchor. It defines the black-stone laboratory, acrylic edge light, aluminum pins, matte ceramic target, exact lime line weight, flat Bebas Neue typography, grain, and color grading.
- **Semantic job:** shows the three practical anchors that make an output testable instead of decorating the article with abstract AI imagery.

## Frame 2: practice as a loop

- **Story beat:** skill grows through a short cycle of task, prompt, output inspection, and one revision.
- Visual proof: four physical stations form a circular optical track; a single acrylic instruction strip travels through a target clamp, a photographic output frame, a magnifying lens, and a revision pin.
- Composition: circular process loop / four-station material sequence.
- **RU text:** `ПРАКТИКА ИДЕТ ПО ЦИКЛУ`; sequence `ЗАДАЧА → ПРОМПТ → ПРОВЕРКА → ПРАВКА`.
- **EN text:** `PRACTICE RUNS IN A LOOP`; sequence `TASK → PROMPT → REVIEW → REVISION`.
- Text mode: sequence
- Style continuity: inherit the style anchor's materials, flat typography, exact palette, optical rail, pins, cool light, and grain. Do not copy its layout, camera, or object composition.
- **Semantic job:** visualizes deliberate iteration as a repeatable learning method rather than a collection of saved prompt examples.

## Frame 3: constrain one generated asset

- **Story beat:** a named GPT Image 2 exercise becomes useful when the prompt locks one object, one frame, and explicit exclusions.
- Visual proof: one matte black mug is isolated inside a wide photographic gate; three aluminum shutters close around the scene to exclude letters, extra objects, and packaging.
- Composition: hero object / mechanical constraint gate around one photographic subject.
- **RU text:** `ОГРАНИЧЬТЕ РЕЗУЛЬТАТ`; labels `ОДИН ОБЪЕКТ`, `ОДИН КАДР`, `БЕЗ НАДПИСЕЙ`.
- **EN text:** `CONSTRAIN THE OUTPUT`; labels `ONE OBJECT`, `ONE FRAME`, `NO TEXT`.
- Text mode: annotated-explainer
- Style continuity: inherit the style anchor's stone, smoked acrylic, flat typography, exact lime rails, aluminum hardware, target material, lighting, and grain. Do not copy its layout, camera, or object composition.
- **Semantic job:** makes the practical-case correction visible through physical boundaries instead of presenting two competing outputs.

## Frame 4: choose a course by practice

- **Story beat:** course quality is visible in the work cycle it asks the learner to complete.
- Visual proof: a perspective path of three large drafting stations leads toward one finished artifact: a task sheet, a marked feedback lens, and a transfer exercise with a new target object.
- Composition: receding workshop path / decision journey with three milestones.
- **RU text:** `ВЫБИРАЙТЕ ПРАКТИКУ`; sequence `ЗАДАЧА → ОБРАТНАЯ СВЯЗЬ → НОВЫЙ КЕЙС`.
- **EN text:** `CHOOSE PRACTICE`; sequence `TASK → FEEDBACK → NEW CASE`.
- Text mode: sequence
- Style continuity: inherit the style anchor's laboratory materials, flat typography, exact palette, optical rail, pins, ceramic target, cool light, and grain. Do not copy its layout, camera, or object composition.
- **Semantic job:** turns course selection into a concrete inspection of exercises, feedback, and transfer instead of a decorative certificate scene.

## Pairing and production rules

1. Generate the cover separately without text.
2. Generate RU frame 1 with `seo2/Reference/bebas-neue-font-reference.png` as the only initial reference and inspect every Cyrillic word.
3. Use approved RU frame 1 as the style reference for RU frames 2-4, explicitly forbidding layout, camera, and composition copying.
4. Create each EN frame as a localization edit of its approved RU sibling: change only the text, preserve objects, layout, camera, light, optical rails, grain, and color.
5. Resize, compress, and convert only. Never add, replace, or redraw text after generation.
